# Stage IV Workflow

# Can an Engineered Local Potential Reopen the Quantum Mpemba Effect?

---

# 1. 研究目标

Stage IV 的核心问题是：

> 当 exponentially decaying XY interaction 处于一个没有明显 QMPE 的参数区域时，
> 加入保持 \(U(1)\) symmetry 的 local site-energy potential，
> 是否能够重新产生 Quantum Mpemba Effect (QMPE)？

研究逻辑为

\[
\boxed{
\text{Exponential XY}
\rightarrow
\text{QMPE OFF}
\rightarrow
+\sum_i h_i\sigma_i^z
\rightarrow
\text{QMPE ON?}
}
\]

这里必须强调：

\[
\boxed{
\text{“local potential 能 reopen QMPE”是待检验 hypothesis}
}
\]

而不是预设结论。

Stage IV 最终希望回答三个层次的问题：

1. **Existence**
   \[
   \text{QMPE 能不能 reopen？}
   \]

2. **Control**
   \[
   \text{什么类型、什么强度的 }h_i\text{ 能 reopen？}
   \]

3. **Mechanism**
   \[
   h_i\text{ 为什么改变 relaxation hierarchy？}
   \]

---

# 2. Stage IV 的前置条件

Stage IV 不能独立开始。

必须首先完成 Stage II：

\[
J_{ij}
=
J_{\rm NN}
e^{-(|i-j|-1)/\xi}.
\]

通过扫描

\[
\xi
\]

找到至少一个没有 robust early-time QMPE 的参数：

\[
\boxed{
\xi=\xi_{\rm off}.
}
\]

要求：

\[
M(\xi_{\rm off},h_i=0)\approx0
\]

并且在规定的 early-time observation window 中没有 robust crossing：

\[
D(t)>-\epsilon.
\]

因此 Stage IV 的 baseline 必须明确满足：

\[
\boxed{
\text{Exponential XY at }\xi_{\rm off}
=
\text{QMPE OFF}.
}
\]

如果 Stage II 中 exponential XY 对所有合理 \(\xi\) 都存在 robust QMPE，
那么就不能声称进行“reopening”。

这时应该修改问题为：

> local potential 如何增强、减弱或控制 QMPE？

---

# 3. Baseline Hamiltonian

定义 exponential XY Hamiltonian：

\[
\boxed{
H_{\exp}
=
\sum_{i<j}
\frac{J_{ij}}{2}
\left(
\sigma_i^x\sigma_j^x
+
\sigma_i^y\sigma_j^y
\right)
}
\]

其中

\[
\boxed{
J_{ij}
=
J_{\rm NN}
e^{-(|i-j|-1)/\xi}.
}
\]

采用这种 normalization 的原因是：

\[
J_{i,i+1}=J_{\rm NN}
\]

始终成立。

因此改变 \(\xi\) 主要改变 interaction range，
而不是同时改变 nearest-neighbor energy scale。

建议使用：

\[
J_{\rm NN}=1
\]

作为无量纲能量单位。

时间单位为：

\[
\tau=J_{\rm NN}t.
\]

---

# 4. 加入 Local Site-Energy Potential

Stage IV 的总 Hamiltonian：

\[
\boxed{
H
=
H_{\exp}
+
H_{\rm local}
}
\]

其中

\[
\boxed{
H_{\rm local}
=
\sum_{i=1}^{N}
h_i\sigma_i^z.
}
\]

即

\[
H
=
\sum_{i<j}
\frac{J_{\rm NN}
e^{-(|i-j|-1)/\xi}}{2}
\left(
\sigma_i^x\sigma_j^x
+
\sigma_i^y\sigma_j^y
\right)
+
\sum_i h_i\sigma_i^z.
\]

这里的

\[
h_i
\]

就是 Stage IV 的主要控制参数。

---

# 5. 为什么选择 \(\sigma_i^z\) local potential？

整个项目研究的 conserved charge 是

\[
Q
=
\frac12
\sum_i\sigma_i^z.
\]

需要保持

\[
[H,Q]=0.
\]

由于

\[
[\sigma_i^z,Q]=0,
\]

因此

\[
\left[
\sum_i h_i\sigma_i^z,
Q
\right]
=0.
\]

所以加入 arbitrary longitudinal potential 后仍然：

\[
\boxed{
[H,Q]=0.
}
\]

这非常重要。

我们不希望通过显式破坏 \(U(1)\) symmetry 来制造 EA dynamics。

我们真正想研究的是：

\[
\boxed{
\text{在 symmetry-preserving Hamiltonian 内部改变 relaxation dynamics}
}
\]

是否能够控制 QMPE。

每一次 simulation 必须检查：

```python
comm_norm = (H * Q_total - Q_total * H).norm()
